# Навигация для незрячих с сонарным датчиком на собаке-поводыре

**Концепция ассистивной навигационной системы**
**Дата первой публикации идеи:** февраль 2026  
**Дата фиксации на GitHub:** 17 сентября 2026
## Проблема
Незрячие люди, использующие собаку-поводыря, получают ограниченную информацию об окружающей среде. Собака помогает избегать препятствий, но не передаёт детальную картину пространства.

## Суть идеи
Небольшое устройство на собаке-поводыре сканирует пространство ультразвуковыми датчиками. Данные идут на смартфон и превращаются в голосовые подсказки в наушниках («препятствие справа в 1,5 метра», «свободный проход прямо»).

## Основные компоненты
- Компактный датчик на собаке-поводыре
- Передача данных на смартфон в реальном времени
- Обработка в голосовые инструкции
- Вывод через Bluetooth-наушники

## Целевая аудитория
Незрячие и слабовидящие люди, использующие собаку-поводыря.
